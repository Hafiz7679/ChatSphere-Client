# ChatSphere Client

Frontend for the ChatSphere real-time messaging platform.

See the [root README](../README.md) for full project documentation.

## Quick Start

```bash
cd client
npm install
npm run dev
```

Environment variables (`.env`):

```
VITE_API_URL=http://localhost:5000/api
VITE_SOCKET_URL=http://localhost:5000
```

## Build

```bash
npm run build
```

Output goes to `client/build/`.

## Tech

React 19, Vite, Tailwind CSS 3, Zustand, Socket.IO Client, Axios
